# 산소계산소 (O₂ PACE CALC)

내 레이스 기록으로 VDOT과 훈련 페이스를 계산하는 러닝 사이트입니다.

- VDOT 페이스 계산기 (5K · 10K · 하프 · 풀, 상위 % 표시)
- 오늘 러닝 판정 (페이스 · 평균 심박 · 2분 심박 회복)
- 내 기록 저장 (VDOT 변화 · 심박 회복 추세, 브라우저에 저장)
- 칼로리 · 목표 체중 계산기

## 참고 자료
- Jack Daniels, *Daniels' Running Formula* — VDOT (Daniels–Gilbert 공식)
- ACSM 러닝 대사 공식 — 칼로리 계산
- Shetler et al. (2001) — 2분 심박 회복 기준
- Fetch Everyone race time percentiles — 상위 % 비교

계산 결과는 추정치이며 의학적 조언이 아닙니다. 잭 대니얼스 및 관련 상표권자와 제휴 관계가 없습니다.
